# Chrome Web Store 繁體中文文案

## 名稱

ChatGPT EDU Prompt Assistant (TW)

## 簡短說明

台灣教育提示詞側邊欄：196 則中英模板、填空預覽、收藏、自訂提示詞、備份與 Chrome 同步。

## 詳細說明（貼入商店）

由數位敘事力期刊開發，協助老師與學習者把教育任務整理成清楚、可重複使用的提示詞。

14 類、196 則任務，均提供繁體中文與英文版本。涵蓋教學設計、親師溝通、教育行政、學生學習、華語文、研究、程式、圖像、引導學習、互動視覺化、搜尋查證、資料分析、Projects 與文件協作。

在 Chrome 原生側邊欄搜尋、收藏或新增自己的提示詞。點開模板、填寫欄位、檢查完整預覽，再複製填妥內容到 ChatGPT。文件圖示可插入模板原文；原輸入框有草稿時會先詢問取代。所有訊息均由你確認送出。

學習模板包含先備診斷、漸進提示、獨立練習及新情境檢核。工作流程模板強調來源、專用交付格式和可檢查結果；課綱、引用或資料不足時要求先問或標示待查。

支援自訂提示詞新增、編輯、刪除與優化指令，JSON 備份及合併匯入，常用欄位與黑白明暗外觀。自訂提示詞、收藏與設定可透過 Chrome 同步；填寫紀錄只存本機。優化指令由你送出，滿意後自行貼回編輯器。

不需要 API Key，不提供自有後端或廣告追蹤，不讀聊天歷史、不擷取 AI 回覆、不自動送出。使用 ChatGPT 的圖像、研究或資料工具仍依帳號與工作區實際可用功能；檔案、模型與工具需自行操作。AI 結果應由人員覆核，避免輸入可辨識學生資料。

需要 Chrome 116 以上。ChatGPT 原文插入只支援 chatgpt.com／chat.openai.com 對話頁；其他網站仍可瀏覽與複製。此工具非 OpenAI 官方產品，未與 OpenAI 隸屬或合作。
