## 驗證證據

- 14 項 Node 測試：CRUD、重新載入、儲存失敗回滾、無效備份、合併、衝突、刪除防復活、UTF-8 分塊、同步額度／缺塊與本機資料界線。
- 全 392 份模板：ID、分類數、欄位 ID／標籤、選項、雙語對應、無重複全文、逐欄填入與預覽、鷹架文字及資料界線檢查；prompt-quality.json 可逐項查閱。
- 完整瀏覽器回歸：搜尋、收藏、自訂 CRUD、替換草稿確認／取消、錯誤與剪貼簿備援、語言保留、主題、匯入／匯出、同步重試、清除紀錄、300–812px 排版、字級調整、reduced-motion；零 page errors。
- content.js：現代 contenteditable、舊 textarea、多行純文字、HTML 不解析、草稿變動拒絕、對話框排除。
- 真正 MV3 實載：Chrome for Testing 獨立暫存設定檔，驗證 CSP、模組、service worker、本機儲存、content script 註冊及 panel→worker→composer。網頁文件為合成 ChatGPT 結構，不是登入後遠端對話。
- 最終執行 ZIP 解壓後再次實載，通過相同 MV3 完整路徑；包內 16 檔案、manifest 根目錄、JSON 數量與 CRC 均檢查。提交包包含商店文案、隱私、圖片、報告與內嵌執行 ZIP，另提供 SHA-256。
- npm 鎖定依賴檢查當次回報零漏洞；此結果僅涵蓋依賴資料庫，正式擴充功能無第三方執行依賴。

## 內容品質判準與限制

新增工作流程以每則任務的必要輸入、可交付物、來源定位、可檢核結果與未知處理檢查；不是只看共有安全句。學習與引導類32則要求診斷／一次一問／適應／提示退場／遷移；教學、華語與視覺化38則要求教材中的可觀察學習證據。其他類依流程或工具設計，不硬套互動教學模式。

共同資料界線將填入素材視為資料，要求缺素材先問、去識別與人員覆核；不代表保證抵抗所有模型注入。部分研究、行政與華語內容需專業使用者核實；沒有逐則送至ChatGPT評估輸出，也沒有課堂成效試驗，矩陣的 modelOutcome 明列 not-run。
