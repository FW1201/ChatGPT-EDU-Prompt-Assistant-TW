# English Chrome Web Store listing

## Name

ChatGPT EDU Prompt Assistant (TW)

## Short description

Education prompt sidebar: 196 bilingual templates, fill-in previews, favorites, custom prompts, backups and Chrome Sync.

## Detailed description

Developed by Journal of Digital Narrative for teachers and learners using reusable education prompts, with a focus on Taiwan education contexts.

Browse 196 tasks in 14 categories, each available in Traditional Chinese and English: teaching, parent communication, administration, learning, Mandarin, research, programming, images, guided study, visualizations, search, data, Projects and writing.

Search across the library, save favorites, fill template fields and review the complete preview. Copy the filled prompt into ChatGPT yourself. The document icon inserts the unfilled original template, with confirmation before replacing an existing draft. You always decide when to send.

Learning prompts include diagnosis, progressively adjusted support, independent practice and transfer checks. Workflow templates ask for sources, task-specific deliverables and verifiable results rather than invented facts. AI output still requires human review.

Create, edit and delete custom prompts; generate revision instructions; export JSON backups and merge imports. Chrome Sync can synchronize prompts, favorites, defaults and preferences when enabled. Saved form entries stay local. Revision results must be reviewed and pasted back by the user.

No API key, developer collection server, ads or analytics. The extension does not read chat history, capture AI replies, attach files, switch models or automatically send messages. ChatGPT feature availability varies by account and workspace. De-identify student information before using any AI service.

Requires Chrome 116 or later. Original-template insertion supports conversations on chatgpt.com and chat.openai.com; browsing and copying remain available elsewhere. This is an independent tool, not affiliated with or endorsed by OpenAI.
